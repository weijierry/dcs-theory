# DCS: 因果结构演化论 (Causal Structure Evolution Theory)

DCS (Dynamic Causal Structure) is a cross-scale causal framework that seeks the first principles of evolution — from the causal structure of the early universe, through matter, life, brains, and minds, to human civilization and AI.

## Core thesis

Evolution is not just an increase in complexity. It is the process by which retained causal structures become typed, composable, and certifiable across scales. The finite-core preprint formalizes what it means for a coarse-grained model to preserve the causal targets, persistence events, and action contracts that motivated it.

## Scientific boundary

This repository currently hosts the finite-state, discrete-time, classical-Markov certification core. Broader claims about physics bridging, life, intelligence, civilization, and discriminating empirical predictions are explicitly marked as future work.
