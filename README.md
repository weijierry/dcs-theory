# DCS: 因果结构演化论 (Causal Structure Evolution Theory)

DCS (Causal Structure Evolution) is a cross-scale causal framework that seeks the
first principles of evolution — from the causal structure of the early universe,
through matter, life, brains, and minds, to human civilization and AI.

## Core thesis

Evolution is not just an increase in complexity. It is the process by which
retained causal structures become the starting point of the next level:

**CPIR cycle:** Possibility expansion → Dynamical filtering → Structural persistence → Encapsulation and coarse-graining → Causal compression → New macro-level causal efficacy → Formation of a new level → New possibilities open again.

In one sentence: a layer transition happens when a macro-level structure gains
its own predictive and intervention capability, while the lower-level complexity
is partially encapsulated.

## Scope and boundaries

This work is a research program, not a claim of final truth. The project
explicitly maintains distinctions between:

- Finite-model certification results (verified computationally)
- External established theorems (cited)
- Conditional DCS propositions
- Conjectures
- Future work (P2B, life dual-contracts, intelligence capability lattice,
  physical bridge, 6.0 discriminating predictions)

All machine-verifiable results in the preprint are reproducible via the
reproduction package in this repository.
